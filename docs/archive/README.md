# Archive — the done side

This folder holds the parts of the living documentation that describe work already implemented. It exists so that each maintained document in `docs/` can be read as a to-do list: what is left, and nothing else.

Nothing here is deleted history. The wording is preserved as it was written, including the implementation notes and decisions worth carrying forward, so that a decision made months ago can still be recovered with its reasoning intact.

## Rules for this folder

- A live document never refers to an item that lives here. When work completes, remove it from the live document and add it to the matching archive file, then append the dated entry to [changelog.md](../changelog.md).
- Archive files are append-only in spirit: correct an inaccuracy, but do not quietly rewrite what was delivered.
- `docs/changelog.md` stays outside this folder. It is the dated ledger of every pass and is written to continuously, so it belongs with the live set.
- `docs/hotspot-report.md` also stays outside this folder. It is regenerated by `npm run report:hotspots` and always describes current geometry.
